# dstl8

CLI and TUI for the [dstl8](https://dstl8.ai) observability platform.

## Install

```sh
npm install -g dstl8
```

Or run directly:

```sh
npx dstl8
```

This package downloads the correct prebuilt binary for your platform during installation.

## Other install methods

```sh
brew install control-theory/dstl8/dstl8
curl -fsSL https://install.dstl8.ai/script/dstl8-cli | sh
nix run github:control-theory/dstl8
```
