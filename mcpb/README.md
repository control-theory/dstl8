# dstl8 — Claude Desktop Extension

MCP server extension for [Dstl8](https://dstl8.ai), an AI-native observability platform.

## Prerequisites

The `dstl8` CLI must be installed and authenticated:

```sh
brew install control-theory/dstl8/dstl8
dstl8 login
```

## Install

Download `dstl8-{version}.mcpb` from the [latest release](https://github.com/control-theory/dstl8/releases/latest) and double-click to install in Claude Desktop.

## What it does

Once installed, Claude can query your Dstl8 org directly:

- Search and analyze logs
- View sentiment and severity heatmaps
- List and inspect incidents
- Get anomaly detection results
- Query AI-generated summaries

The extension uses your local `dstl8` credentials — no additional configuration needed.
